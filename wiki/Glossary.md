# Glossary

Authoritative definitions of VOID//OCULUS terminology. New terms are added here **before** being used in other pages ([Conventions § Documentation Standards](Conventions#documentation-standards)). Alphabetical.

---

| Term | Definition |
|---|---|
| **ADR** | Architecture Decision Record — a numbered entry in [Design Decisions](Design-Decisions) capturing context, decision, alternatives, and consequences. |
| **Blink cascade** | The synchronized blink wave that sweeps across all eyes roughly every 40 seconds, in addition to each eye's individual randomized blinks (2.6–13.6 s intervals). |
| **Boot animation** | The ocular startup sequence played on page load before the canvas becomes interactive. |
| **Canvas (world) coordinates** | Positions measured from the top-left of the 8000×6000 px virtual canvas, independent of pan/zoom. Card `style.left/top` values live in this space. See [Architecture § Coordinate Systems](Architecture#coordinate-systems). |
| **Canvas engine** | The first `<script>` block in `index.html`: state, transforms, cards, connections, selection, minimap, particles, and event wiring. Contrast with *Oculus engine*. |
| **Card** | The atomic content unit on the canvas: an absolutely positioned `div` with a `data-type`, a unique id (`card-<n>`), and HTML content. Types: `sticky`, `code`, `def`, `eye`. |
| **Connection (link)** | A directed record `{ from, to, color, id }` in `state.connections`, rendered as a glowing cubic-bezier SVG path between two card centers. |
| **Connector layer** | The `#connector-svg` element inside `#canvas` where all connection paths are drawn; `pointer-events: none`, rebuilt as a batch by `renderConnectors()`. |
| **Crypts** | Dark elliptical voids drawn inside a procedural iris, between the stroma fibers and the pupil. |
| **Dilation** | The reactive pupil-size response to zoom level, reported as `DILATION %` in the status bar and driven by `ocularTick()`. |
| **Eye node** | A card of type `eye` containing a procedurally generated iris that tracks the pointer and blinks. Created via `addEyeCard()`. |
| **Fovea map** | The stylized minimap — the bottom-corner overview of the whole canvas with a viewport rectangle; clicking it jumps the view. |
| **Gaze tracking** | The ~30 fps `gazeLoop()` behavior rotating each on-screen eye's pupil toward the pointer; off-screen eyes are culled. |
| **Iris (procedural)** | SVG markup generated by `iris(opt)` from a deterministic seed: sclera, veins, stroma fibers, crypts, pupil, highlight, limbal ring. |
| **Limbal ring** | The dark ring at the outer edge of an iris, drawn last for definition. |
| **Link tool** | The ⊸ toolbar mode implementing the two-click connection state machine (source → `⊸ SELECT TARGET NODE` → target). |
| **Macro iris** | The giant decorative iris (center `MX=1560, MY=1480`, radius `MR=2450` in world coordinates) visible when zoomed far out. |
| **Oculus engine** | The second `<script>` block: an IIFE containing all ocular/decorative systems, exposing only `window.addEyeCard` ([ADR-007](Design-Decisions#adr-007-ocular-engine-isolated-in-an-iife)). |
| **PAL** | The palette table mapping names (`phosphor`, `crimson`, `violet`, `amber`, `cyan`, `bone`) to `[bright, dim, dark]` color triples used by the iris generator. |
| **Particle field** | The ambient animated background rendered on the `#particles-bg` canvas via `requestAnimationFrame`. |
| **Phosphor** | The primary accent color family (`--phosphor: #00ff9d` by default); semantically "primary", regardless of the actual hue a theme assigns. |
| **Scan-lines** | The CRT-style horizontal line overlay rendered in the ocular overlay layer. |
| **Selection box** | The rubber-band rectangle (`#selection-box`) drawn when dragging on empty canvas with the SELECT tool; cards intersecting it become selected. |
| **Smoke checklist** | The canonical ~5-minute manual verification protocol in [Testing](Testing#smoke-checklist); the minimum bar for any PR. |
| **State** | The single global object holding all logical application data; the DOM is a projection of it. See [Architecture § State Model](Architecture#state-model). |
| **Stroma** | The radial fiber pattern of a procedural iris, drawn with quadratic curves; count controlled by the `fibers` option. |
| **Sticky note** | A card of type `sticky` with a color variant (`sticky-green`, `sticky-red`, `sticky-violet`, `sticky-amber`, `sticky-cyan`) and a label (IDEA, TODO, …). |
| **Tool** | The active interaction mode in `state.tool`: `select`, `pan`, or `connect`; switched by `setTool()` and the toolbar. |
| **Transform** | The single CSS `translate(...) scale(...)` applied to `#canvas` by `applyTransform()` implementing pan/zoom ([ADR-006](Design-Decisions#adr-006-single-css-transform-for-panzoom)). |
| **Viewport coordinates** | Positions in CSS pixels measured from the top-left of the browser window; the space of raw mouse events and fixed overlays. |
| **Vignette** | The edge-darkening radial gradient in the ocular overlay that gives the screen its depth. |
| **World coordinates** | Synonym for *canvas coordinates*. |
| **Zero-build** | The property that the application requires no compilation, bundling, or package installation — `index.html` is both source and artifact ([ADR-001](Design-Decisions#adr-001-single-file-zero-build-architecture)). |
| **Zoom clamp** | The enforced scale range `[0.06, 3.0]` in `zoom()`. |
